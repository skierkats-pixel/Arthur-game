# Arthur's Awakening (MVP)

A cozy, light-strategy web prototype for "Arthur's Awakening". Emily can move around a nursery, feed baby Arthur, change diapers, and earn Parenting XP while Arthur's needs decay over time.

## Getting Started

1. Open `index.html` in your browser (no build steps required).
2. Use **WASD/Arrow keys** to move Emily.
3. Stand near the crib or changing table and press **E** to perform an action.
4. Keep Arthur's Hunger and Comfort above zero to prevent stress.

## MVP Features
- 2D movement with a simple nursery layout rendered on canvas.
- Hunger and Comfort meters that decay over time; when empty, Emily's Stress increases.
- Two core actions with progress indicators: **Feed Arthur** and **Change Diaper**.
- Parenting XP (PXP) earned for successful actions with quick feedback to the player.
- Accelerated in-game clock tracking days and minutes.
